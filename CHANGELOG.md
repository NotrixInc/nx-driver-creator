# Changelog

## [0.1.0] - 2026-02-17

### Added
- Initial release
- Create Driver wizard with device, hub, and child templates
- Build Driver command (go build)
- Package Driver command (nx-driver-packager pack)
- Verify Package command (nx-driver-packager verify)
- Run Driver Locally command
- Add Endpoint interactive wizard
- Add Variable interactive wizard
- NX Drivers explorer sidebar with tree view
- Auto-detection of driver projects via manifest.json
- File watchers for manifest/endpoints/variables changes
- Extension configuration for SDK, templates, and packager paths
